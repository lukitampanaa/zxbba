00

Definisi Logaritma

ₐlog c = b ⟺ aᵇ = c

Logaritma adalah invers dari perpangkatan. Jika aᵇ = c, maka logaritma basis a dari c adalah b.

ₐlog c = b  ⟺  aᵇ = c

Syarat: a > 0, a ≠ 1 (basis), c > 0 (numerus).

Contoh: ₂log 8 = 3, karena 2³ = 8.
01

Logaritma Umum & Natural

log x · ln x

Logaritma umum — basis 10log x = ₁₀log x
Logaritma natural — basis e ≈ 2,718ln x = ₑlog x
Konvensi: penulisan “log” tanpa basis berarti basis 10, sedangkan “ln” berarti basis e (bilangan Euler).
02

Logaritma dari 1

ₐlog 1 = 0

ₐlog 1 = 0   ·   a > 0, a ≠ 1

Sebab bilangan berapa pun dipangkatkan 0 hasilnya 1 — yakni a⁰ = 1.

Contoh: ₅log 1 = 0 · ₁₀log 1 = 0.
03

Logaritma Basis Sendiri

ₐlog a = 1

ₐlog a = 1

Sebab a¹ = a, logaritma suatu basis terhadap dirinya sendiri selalu 1.

Contoh: ₃log 3 = 1 · ₇log 7 = 1.
04

Logaritma Perkalian

ₐlog (b·c) = ₐlog b + ₐlog c

ₐlog (b × c) = ₐlog b + ₐlog c

Logaritma dari perkalian terurai menjadi jumlah logaritma tiap faktor.

Contoh: ₂log 12 = ₂log (4×3) = ₂log 4 + ₂log 3 = 2 + ₂log 3.
05

Logaritma Pembagian

ₐlog (b⁄c) = ₐlog b − ₐlog c

ₐlog (b ⁄ c) = ₐlog b − ₐlog c

Logaritma dari pembagian sama dengan selisih logaritma pembilang dan penyebut.

Contoh: ₂log (8⁄2) = ₂log 8 − ₂log 2 = 3 − 1 = 2.
06

Logaritma Perpangkatan

ₐlog bⁿ = n · ₐlog b

ₐlog bⁿ = n × ₐlog b

Pangkat pada numerus turun menjadi koefisien di depan logaritma.

Contoh: ₂log 8 = ₂log 2³ = 3 × ₂log 2 = 3.
07

Pangkat pada Basis

ₐₘlog bⁿ = (n⁄m) · ₐlog b

aᵐlog bⁿ = (n ⁄ m) × ₐlog b

Pangkat pada basis dan numerus keluar sebagai faktor pecahan n⁄m.

Contoh: ₄log 8 = ₂²log 2³ = (3⁄2) × ₂log 2 = ³⁄₂.
08

Perubahan Basis

ₐlog b = ᶜlog b ⁄ ᶜlog a

ₐlog b = ᶜlog b ⁄ ᶜlog a

Memindahkan logaritma ke basis baru — berguna saat basis tidak tersedia di kalkulator.

Contoh: ₃log 5 = log 5 ⁄ log 3 (dipindah ke basis 10).
09

Rantai Logaritma

ₐlog b × ᵦlog c = ₐlog c

ₐlog b × ᵦlog c = ₐlog c

Jika numerus log pertama sama dengan basis log kedua, keduanya menyusut menjadi satu log.

Contoh: ₂log 3 × ₃log 8 = ₂log 8 = 3.
10

Invers Logaritma

ₐlog b = 1 ⁄ ᵦlog a

ₐlog b = 1 ⁄ ᵦlog a

Menukar basis dan numerus menghasilkan nilai kebalikannya.

Contoh: ₂log 5 = 1 ⁄ ₅log 2.
11

Antilogaritma

a^(ₐlog b) = b

aₐlog b = b

Basis yang dipangkatkan logaritmanya sendiri kembali ke numerus semula.

Contoh: 2₂log 8 = 8.
